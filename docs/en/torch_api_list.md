# torch_extension APIs

## How to Use

To simplify operator calling, the project provides a set of APIs compatible with the native PyTorch style. This API uses the JIT mechanism (`torch.utils.cpp_extension.load`) of PyTorch to compile the C++ Kernel Wrapper in real time when it is called for the first time and bridge the PyTorch function to the aclnn API of CANN. In addition, GE Converter supports the TorchAir graph mode, helping developers build models and applications.

- **Software Package Description**

  Before calling a torch_extension API, ensure that the CANN Toolkit, ops-transformer, and Ascend for PyTorch packages have been installed.

- **Calling Method**

  When the torch_extension API is called, the `cann-ops-transformer` module is required, which is defined in `${INSTALL_DIR}/python/sitepackage/cann-ops-transformer`. `${INSTALL_DIR}` indicates the file path after CANN installation.

  ```python
  import torch
  import torch_npu
  import cann_ops_transformer
  ```

- Version Evolution

  Note that some APIs have multiple versions. Select the latest version. (APIs of a later version are compatible with all capabilities of an earlier version.)
