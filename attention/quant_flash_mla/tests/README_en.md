# quant\_flash\_mla\_with\_kvcache Test Suite

English | [简体中文](./README.md)

TTK E2E tests and pytest tests for the MLA FP8 quantized Flash Attention (with KV cache) operator.

## Directory Structure

```
tests/
├── assets/                              # TTK plugin directory (--plugin points to this directory)
│   ├── _xlsx_minireader.py              # Dependency-free xlsx reader (zipfile + minidom)
│   ├── excel_to_csv.py                  # xlsx to TTK CSV conversion script
│   ├── qfmla_golden.py      # MLA FP8 golden reference implementation
│   ├── spec.py                          # TTK TestSpec registration (including torch_graph)
│   └── impl/                            # TTK plugin implementation
│       ├── inputs.py                    # customize_inputs: generate BNSD FP8 data -> convert to target layout -> write to tensor slots
│       ├── golden.py                    # golden: set global variables -> generate CPU data -> call the golden function -> convert to target layout
│       ├── compare.py                   # compare: NPU vs golden accuracy comparison (rtol/atol/PctThd)
│       ├── npu_preprocess.py            # npu_preprocess: call the metadata operator to generate metadata -> backfill the slot
│       └── graph.py                     # aclgraph compilation target (QuantMlaAclGraph)
│
├── pytest/qfmla_mxfp8_test/             # pytest test directory (aligned with the mxfp8 style)
│   ├── excel_to_pytest_paramset.py      # xlsx to pytest paramset (TEST_PARAMS dictionary)
│   ├── pytest_paramset_to_csv.py        # pytest paramset to TTK e2e CSV
│   ├── quant_flash_mla_paramset_common.py  # Common expansion logic (expand_paramset_to_cases)
│   ├── quant_flash_mla_paramset_debug.py   # Automatically generated case set
│   ├── test_quant_flash_mla_func_rdv.py # pytest test entry
│   ├── conftest.py                     # pytest plugin (--golden-mode, --cache-dir)
│   ├── pytest.ini                      # pytest marker definitions
│   └── common/
│       ├── __init__.py
│       └── test_runner.py              # Test runner (four stages: gen -> cpu -> npu -> compare)
│
├── qfmla_excel.csv                      # CSV currently used by TTK tests (generated by excel_to_csv.py)
├── ttk_mla_run.sh                      # TTK run script (source CANN + conda + custom_transformer)
└── validate_red_tnd.py                 # TND format validation script
```

## pytest Testing

### 1. Excel → pytest paramset

```bash
cd tests/pytest/qfmla_mxfp8_test
python excel_to_pytest_paramset.py --xlsx /home/z00954345/red_modified.xlsx --sheet 1
```

### 2. Run pytest

```bash
cd tests/pytest/qfmla_mxfp8_test
pytest test_quant_flash_mla_func_rdv.py -v
```

`--golden-mode` supports staged execution:

| Mode | Description |
|------|------|
| `all` (default) | Full flow: generate data -> CPU golden -> NPU execution -> accuracy comparison |
| `gen` | Generate data only |
| `cpu` | Run CPU golden only |
| `npu` | Run NPU only |
| `compare` | Run accuracy comparison only |

Example: `pytest test_quant_flash_mla_func_rdv.py -v --golden-mode=npu,compare`

### 3. pytest paramset → TTK CSV

```bash
python pytest_paramset_to_csv.py --paramset quant_flash_mla_paramset_debug --output qfmla_pytest.csv
```

## TTK Execution Flow

```
TTK reads the CSV
  │
  ├─ 1. customize_inputs (assets/impl/inputs.py)
  │     ├─ Set golden global variables (B, N_q, D, softmax_scale, SCALE_VALUE, and so on)
  │     ├─ generate_data() generates BNSD FP8 data (CPU, same seed as golden)
  │     ├─ convert_q_bnsd_to_layout() → TND layout
  │     ├─ Build the PA K cache (BnNBsD / BnBsND / NZ)
  │     └─ Write to the 10 tensor slots
  │
  ├─ 2. npu_preprocess (assets/impl/npu_preprocess.py)
  │     └─ Call quant_flash_mla_metadata() → backfill the metadata slot
  │        (supports dynamic slots -1,-1 and static slots with resize_/copy_)
  │
  ├─ 3. NPU execution
  │     └─ torch.ops.cann_ops_transformer.quant_flash_mla() → attn_out, lse_out
  │
  ├─ 4. golden (assets/impl/golden.py)
  │     ├─ Set the same global variables (including SCALE_VALUE = softmax_scale)
  │     ├─ generate_data() generates the same BNSD FP8 data
  │     ├─ fp8_fullquant_mla_golden() CPU reference computation
  │     └─ Convert to the target layout → bf16
  │
  └─ 5. compare (assets/impl/compare.py)
        └─ isclose(rtol=0.0078125, atol=0.0001) → PctThd=99.5% → Pass/Fail
```

## 10 Tensor Slots

| # | Name | dtype | Description |
|---|------|-------|------|
| 0 | q | float8_e4m3fn | Q matrix, TND layout `(T, N, D)` |
| 1 | k_cache | float8_e4m3fn | KV cache, PA layout |
| 2 | q_descale | float32 | Q dequantization scale, shape `(T, N)` |
| 3 | k_descale | float32 | K dequantization scale, shape `(1,)` |
| 4 | block_table | int32 | KV cache block indices |
| 5 | cache_seqlens | int32 | Actual KV cache length of each batch |
| 6 | cu_seqlens_q | int32 | TND: cumulative offset of Q for each batch |
| 7 | seqused_q | int32 | Actual token count of Q for each batch |
| 8 | attn_mask | int8 | Provides the causal mask `(2048, 2048)` when mask_mode=3 |
| 9 | metadata | int32 | Scheduling information generated by the metadata operator |

## Three Modes of the metadata Slot

| Excel metadata_shape | CSV Output | Behavior |
|----------------------|-----------|------|
| `-1,-1` | `(-1, -1)` | Dynamic slot; npu_preprocess generates and returns a new tensor |
| Concrete value such as `2,4096` | `(2, 4096)` | Static slot; npu_preprocess uses resize_ + copy_ |
| Empty / `0,0` | `(2, 4096)` | Default value (actual output of the current NPU metadata op) |

## Key Conventions

| Item | Value |
|------|-----|
| layout_q / layout_out | TND (enforced) |
| quant_mode | 1 (FP8_E4M3FN); the original HIFP8 is converted automatically |
| TND padding | T = B × Q_S (padded), cu_seqlens_q[-1] = T |
| Accuracy threshold | rtol=0.0078125, atol=0.0001, PctThd=99.5% |
| softmax_scale | Passed through to the golden SCALE_VALUE when specified in Excel; defaults to 1/sqrt(D) when not specified |
