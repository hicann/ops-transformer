# GQA Operator Test Framework

English | [简体中文](./README.md)

## File Structure

```text
pytest/
├── test.py                          # Main program for running generalized pytest test cases
├── testcases.py                     # Input parameter configuration for generalized test cases
├── check_valid_param.py             # Input parameter checking and accuracy comparison
├── gqa_no_quant_bnsd_bsnd.py        # CPU-side operator logic implementation for obtaining the Golden result; direct NPU operator invocation
├── gqa_no_quant_bnsd_bsnd_ge.py     # Graph-mode compilation invocation; accuracy comparison against the single-operator invocation result
├── pytest.ini                       # Creates test markers for single-operator CI and graph mode
```

## Overview

As a lightweight test framework for accuracy comparison, the pytest framework provides a simplified verification method and workflow:

- Test cases only need to run one test.py script, which simplifies execution and allows test cases to be generalized
- Supports adaptation of a self-generated custom package; you can verify by directly invoking the custom package without a delivery package
- Functions are separated within scripts, which facilitates feature verification and custom modifications
- The Golden generation logic is complete: inputs are constructed first and computation is performed afterwards
- Environment setup is simple and free of dependency conflicts; only a Python environment and the installation of torch and TorchNPU are required

## Function Description

Based on the pytest test framework, this framework verifies the functions of the GQA operator:

- **CPU side**: Reproduces the operator logic to generate Golden data
- **NPU side**: Invokes the operator directly through TorchNPU to obtain actual data, and feeds it into the graph through the torchair component
- **Accuracy comparison**: Compares CPU and NPU results to verify the operator function

### Key Features

- **Implementation logic**: Reproduces the operator logic on the CPU to generate the Golden script, compares its accuracy against the operator invocation result, and outputs the accuracy rate as well as the indexes and data of failed data
- **Test case generalization**: Generalizes test cases through pytest. Different parameters are automatically cross-combined at runtime, so manual one-by-one configuration is unnecessary and a large number of cases can be verified at the same time
- **Scenario support**: Supports the GQA non-quantized PA scenario. The Query input format supports BNSD/BSND, and the KV cache in the PA scenario supports BBH and BNBD formats
- **Mode support**: Supports the single-operator mode and graph-mode invocation, and implements the tiling sinking function
- **Parameter configuration support**: Supports modifying configurations in the testcases.py parameter configuration script for custom development
- **Randomness testing**: Based on the test randomness objective, the QKV matrices are randomly generated by torch.randn, the input format is defined by parameters, and the actual sequence length of KV is also a randomly generated list with a length of [batch size, 1~Skv]. You do not need to manually configure each case

### Parameter Restrictions

- **Data format**: FP16 / BF16
- **in_layout**: BSND / BNSD
- **kvcache_layout**: BNBD / BBH
  - The BSND format supports only BBH

## Environment Setup

### Prerequisites

1. Download path of the TorchNPU installation package (replace it with the latest version in time): [TorchNPU Installation Tutorial](https://atomgit.com/Ascend/pytorch)
2. Complete the environment installation and environment variable configuration. For details, refer to [ops-transformer](../../../../README_en.md)

### Custom Package Invocation

Invocation of a custom package is supported.

## How to Run

Run the following commands in the pytest folder:

Single-operator direct invocation + graph mode

```bash
python3 -m pytest -rA -s test.py
```

Single-operator direct invocation

```bash
python3 -m pytest -rA -s test.py -v -m ci
```

Graph mode

```bash
python3 -m pytest -rA -s test.py -v -m graph
```
