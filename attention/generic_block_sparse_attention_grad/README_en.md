## Function Description

+ Operator function: GenericBlockSparseAttentionGrad is the backward computation operator of the generic block sparse attention. It supports two sparse index layouts. For `layoutSparsePattern=1`, Q blocks/tokens are selected by KV block, and `metadataOptional` must be generated through `aclnnGenericBlockSparseAttentionGradMetadata` before the invocation; for `layoutSparsePattern=0`, KV blocks are selected by Q token, and the Metadata API is not called. For specific restrictions, see "Constraints" below.

+ Computation formula:

$$
P = SimpleSoftmax(Mask(Q @ selectedK^{T} \cdot scale), lse)
$$

$$
dP = dO @ selectedV^{T}
$$

$$
dS = P \odot (dP - SoftmaxGrad(dO, O))
$$

$$
dQ = dS @ selectedK \cdot scale
$$

$$
dK = dS^{T} @ Q \cdot scale
$$

$$
dV = P^{T} @ dO
$$

## Constraints

- The sparse layout of `layoutSparsePattern=0` requires `residualBlockMode=1`, and `isConsistentTopk` supports false and true (both values are computed based on the actual sparse indexes and counts). No Metadata is needed, and metadata must be empty; D is [1,256], N1%N2=0 and G=N1/N2≤256; blockShape=[1,Bs]; when G≤128, Bs≤128, otherwise Bs≤64; maskType supports 0/1, and the trailing incomplete block automatically participates in the computation. For detailed shape restrictions, see [API Constraints](docs/aclnnGenericBlockSparseAttentionGrad_en.md#constraints).

- FLOAT16 and BFLOAT16 are supported for query/key/value/dout/out/dQuery/dKey/dValue, and the data types must be the same; lse is FLOAT32.
- For `layoutSparsePattern=1`, you must first call GenericBlockSparseAttentionGradMetadata to generate the metadata and then invoke this operator.
- layoutQ and layoutKv must be the same, with the value TND/BNSD/BSND; under the TND layout, the corresponding cuSeqLengths must be passed in.
- sequsedQOptional/sequsedKvOptional take effect only for TND; for BNSD/BSND, nullptr must be passed, and the actual sequence length is taken from the S dimension of Q/K.
- For `layoutSparsePattern=1`, HeadDim is fixed at 128; the value range of N1/N2 is [1, 128], and N1 % N2 == 0.
- For `layoutSparsePattern=1`, blockShape: blockShapeX supports only 1; blockShapeY must be greater than or equal to 128 and a multiple of 64 (the Cube splits S2 by baseN=128);
- When `layoutSparsePattern=1`, residualBlockMode supports only 0 and maskType supports only 1.
- softmaxPrecision currently supports only 0;
- winLeft/winRight must be -1 when the sliding window is not enabled; nullptr should currently be passed for attenMaskOptional.
- The non-deterministic computation path is used; deterministic computation is not yet supported.
