## Description

- Operator function: Computes the Softmax L1Norm result of the `SparseFlashMla` attention. The Compressed Attention and Sparse Compressed Attention scenarios are supported. This operator is the paired forward API of the `aclnnDenseLightningIndexerKLLossGrad` backward operator, and its output can be used for backward gradient computation. During the call, you must first call the `SparseFlashMlaSoftmaxL1NormMetadata` operator to complete the load balancing computation, and then call this operator to complete the computation process.

- Calculation formula:

    Stage 1: Select the input key based on whether the scenario is sparse

    * If the scenario is sparse:

    $$
    selectedKv = Gather(K, sparseIndices[i]),\ 0 <= i < selectBlockCount
    $$

    * else:

    $$
    selectedKv = K
    $$

    Stage 2: Compute P (SimpleSoftmax)

    $$
    P = SimpleSoftmax(Mask(Q @ selectedKv^{T} \cdot scale), softmaxLse)
    $$

    Stage 3: Compute the Softmax L1Norm

    $$
    softmaxL1Norm = \frac{ReduceSum(P, dim=G)}{G}
    $$

    where $G$ is the number of groups ($G = N1 / N2$).

## Parameter Description

| Parameter Name | Input/Output/Attribute | Description | Data Type | Data Format |
| ------ | -------------- | ---- | -------- | -------- |
| q | Input | Input Q of the attention structure. | FLOAT16, BFLOAT16 | ND |
| k | Input | Input K(V) of the attention structure. | FLOAT16, BFLOAT16 | ND |
| softmax_lse | Input | Output softmaxLse of the forward attention computation. For the calculation formula, see the sparse_flash_mla documentation. | FLOAT32 | ND |
| sparse_indices | Optional input | Attention indices with higher weights selected from k in the sparse scenario. | INT32 | ND |
| cu_seqlens_q | Optional input | Cumulative sum of the number of valid Query tokens in each batch. This parameter is required when the layout is TND. | INT32 | ND |
| cu_seqlens_k | Optional input | Cumulative sum of the number of valid Key tokens in each batch. This parameter is required when the layout is TND. | INT32 | ND |
| seqused_q | Optional input | Number of tokens of q that actually participate in the computation in each batch. | INT32 | ND |
| seqused_k | Optional input | Number of tokens of k that actually participate in the computation in each batch. | INT32 | ND |
| cmp_residual_k | Optional input | Remainder of S2 // cmpRatio in each batch. This parameter must be passed in when k is not empty and mask_mode=3. | INT32 | ND |
| topk_length | Optional input | Actual selectable topk length of k corresponding to each row of q. This parameter is required when mask_mode=0 and sparse indices exist. | INT32 | ND |
| metadata | Optional input | Output of the AICPU operator with tiling offloaded, generated by the `SparseFlashMlaSoftmaxL1NormMetadata` operator. | INT32 | ND |
| softmax_scale | Optional attribute | Scale factor. The default value is 1.0. Recommended value: the reciprocal of sqrt(head_dim). | FLOAT32 | - |
| max_seqlen_k | Optional attribute | Maximum sequence length of k. It is used for output shape inference in the TND dense scenario. The default value is 0. | INT64 | - |
| cmp_ratio | Optional attribute | Compression ratio of k. The value range is 1 to 128. The default value is 1. | INT64 | - |
| mask_mode | Optional attribute | Mask mode for the computation of q and k. 0: No mask. 3: rightDownCausal mode. The default value is 0. | INT64 | - |
| layout_q | Optional attribute | Data layout format of the input q. "BSND" and "TND" are supported. The default value is "BSND". | STRING | - |
| layout_k | Optional attribute | Data layout format of the input k. "BSND" and "TND" are supported. The default value is "BSND". | STRING | - |
| softmax_l1_norm | Output | softmax L1Norm result computed by q and k. The formula is reduceG(softmax)/G. This output is not empty when sparse_indices exists, and is empty in other scenarios. | FLOAT32 | ND |

## Constraints

- Deterministic computation: aclnnSparseFlashMlaSoftmaxL1Norm uses the deterministic implementation by default.
- Only the BSND or TND layout is supported, and layout_q must be consistent with layout_k.
- Constraints on data shapes:
    - B: Generally supported.
    - S1 and S2: Generally supported. S1 and S2 of different lengths are supported.
    - N1: 1 to 128 is supported, and num_heads_q must be divisible by num_heads_k.
    - N2: Only 1 is supported.
    - D: Only 512 is supported.
- Supported mask_mode values:
    - 0: No mask operation is performed.
    - 3: Mask of the rightDownCausal mode, corresponding to the lower-triangle scenario partitioned by the right vertex.
- Value range of cmp_ratio: 1 to 128.
- TND scenario: cu_seqlens_q and cu_seqlens_k must be passed in.
- metadata must be passed in and is generated by the `SparseFlashMlaSoftmaxL1NormMetadata` operator.
