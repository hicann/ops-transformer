## Function

- Description:

  The `aclnnSparseFlashMla` operator implements sparse attention computation based on shared KV (Key=Value). It supports three attention computation use cases: SWA (Sliding Window Attention), CSA (Compressed Sparse Attention), and HCA (Heavily Compressed Attention). This operator is applicable to large language model training and inference use cases. It uses the sliding window and KV compression mechanisms to greatly reduce the overhead of attention computation on long sequences. The call requires the task list `metadata` generated by `aclnnSparseFlashMlaMetadata`.

  **This operator is not recommended for standalone use. Use it together with the aclnnSparseFlashMlaMetadata operator to form a complete workflow.**

  The typical call process is as follows:

  1. Prepare inputs such as `q`, `ori_kv`, `cmp_kv`, sequence length, `block table`, and `sinks`.
  2. Call `aclnnSparseFlashMlaMetadata` to generate `metadata`.
  3. Call `aclnnSparseFlashMla` and pass the `metadata` obtained in the previous step to the main operator.

- Formula:

  $$
  O = \text{softmax}(Q \cdot \tilde{K}^T \cdot \text{softmax\_scale}) \cdot \tilde{V}
  $$

  Among them, $\tilde{K} = \tilde{V}$ (shared KV), and $\tilde{K}$ is concatenated from the original KV within the sliding window and the compressed KV within the causal boundary. The specific KV range actually participating in the computation is determined by the template mode and the mask parameter:

  - Sliding window part (oriKv): For the $i_{S1}$-th Query token, its causal diagonal position is $\text{ori\_threshold} = S2_{act} - S1_{act} + i_{S1} + 1$, and the window range is $[\max(\text{ori\_threshold} - \text{ori\_win\_left} - 1, 0), \text{ori\_threshold} + \text{ori\_win\_right})$.

  - Compressed KV part (cmpKv): The causal boundary threshold is $\text{cmp\_threshold} = \lfloor \frac{\text{ori\_threshold}}{\text{cmp\_ratio}} \rfloor$. In the HCA use case, the consecutive compressed KV within $[0, \text{cmp\_threshold})$ is used; in the CSA use case, compressed KV is collected on demand through TopK indexing, and only blocks with $\text{begin\_idx} < \text{cmp\_threshold}$ are retained.

  The attention computation adopts Online Softmax (Flash Attention V2). The S2 direction is iterated in chunks of 512, and sinks serves as the initial maximum value of the softmax for each row:

  $$
  \text{row\_max}^{(0)} = \text{sinks}[g], \quad \text{row\_sum}^{(0)} = 1.0, \quad O^{(0)} = 0
  $$

  $$
  S^{(t)} = Q \cdot K_{tile}^{(t)T} \cdot \text{softmax\_scale}
  $$

  $$
  \text{row\_max}^{(t+1)} = \max(\text{row\_max}^{(t)}, \max(S^{(t)}, \text{dim}=-1))
  $$

  $$
  \text{row\_sum}^{(t+1)} = \exp(\text{row\_max}^{(t)} - \text{row\_max}^{(t+1)}) \cdot \text{row\_sum}^{(t)} + \sum \exp(S^{(t)} - \text{row\_max}^{(t+1)})
  $$

  $$
  O^{(t+1)} = \exp(\text{row\_max}^{(t)} - \text{row\_max}^{(t+1)}) \cdot O^{(t)} + \exp(S^{(t)} - \text{row\_max}^{(t+1)}) \cdot V_{tile}^{(t)}
  $$

  $$
  O_{final} = O^{(T_{s2})} / \text{row\_sum}^{(T_{s2})}
  $$

- Symbol Description

  | Symbol              | Meaning                                               |
  | ------------------- | --------------------------------------------------------- |
  | Q                   | Query input, shape [G, D] (single row).                   |
  | K_tile_t            | KV data of the t-th S2 tile, where K=V (shared KV).       |
  | S_t                 | Scaled QK attention scores of the t-th tile.              |
  | P_t                 | Softmax probabilities of the t-th tile.                   |
  | O_t                 | Accumulated output after the t-th tile.                   |
  | softmax_scale       | Scale factor, usually the reciprocal of the square root of each attention head dimension. |
  | B                   | Batch Size                                                |
  | S1/S1_act           | Query sequence length/actual valid length.                |
  | S2/S2_act           | Original KV sequence length/actual valid length.          |
  | N1                  | Number of Query heads.                                    |
  | N2                  | Number of KV heads.                                       |
  | G                   | GQA group ratio, G=N1/N2.                                 |
  | D                   | Dimension of each attention head.                         |
  | sinks               | Attention sinks, shape [N1].                              |
  | cmp_ratio           | Compression ratio of cmpKv, used to convert the mask on the cmp side to the KV length before compression. |

## Function Prototype

Each operator uses a [two-phase API](../../../docs/en/context/two_phase_api.md). First call `aclnnSparseFlashMlaGetWorkspaceSize` to obtain the workspace size required for computation and the executor that contains the operator computation process, and then call `aclnnSparseFlashMla` to perform the actual computation.

```c++
aclnnStatus aclnnSparseFlashMlaGetWorkspaceSize(
    const aclTensor *q,
    const aclTensor *oriKvOptional,
    const aclTensor *cmpKvOptional,
    const aclTensor *oriSparseIndicesOptional,
    const aclTensor *cmpSparseIndicesOptional,
    const aclTensor *oriBlockTableOptional,
    const aclTensor *cmpBlockTableOptional,
    const aclTensor *cuSeqlensQOptional,
    const aclTensor *cuSeqlensOriKvOptional,
    const aclTensor *cuSeqlensCmpKvOptional,
    const aclTensor *sequsedQOptional,
    const aclTensor *sequsedOriKvOptional,
    const aclTensor *sequsedCmpKvOptional,
    const aclTensor *cmpResidualKvOptional,
    const aclTensor *oriTopkLengthOptional,
    const aclTensor *cmpTopkLengthOptional,
    const aclTensor *sinksOptional,
    const aclTensor *metadataOptional,
    double           softmaxScale,
    int64_t          cmpRatio,
    int64_t          oriMaskMode,
    int64_t          cmpMaskMode,
    int64_t          oriWinLeft,
    int64_t          oriWinRight,
    char            *layoutQOptional,
    char            *layoutKvOptional,
    int64_t          topkValueMode,
    bool             returnSoftmaxLse,
    const aclTensor *attnOutOut,
    const aclTensor *softmaxLseOutOptional,
    uint64_t        *workspaceSize,
    aclOpExecutor  **executor)
```

## Constraints

- Deterministic computation

  - aclnnSparseFlashMla defaults to a deterministic implementation. Multiple calls with the same input produce the same result.

- Usage constraints

  - The SWA sparse ori_kv use case only supports the SWA template. Pass in only `oriKvOptional`, and also pass in `oriSparseIndicesOptional` and `oriTopkLengthOptional`. In the supporting Metadata API, `oriTopk` is K, the last dimension of oriSparseIndicesOptional; `oriMaskMode` is 0/3/4; `oriWinLeft` and `oriWinRight` take non-negative values only when `oriMaskMode` is 4; and `cmpKvOptional` is not passed in.
  - In the SWA sparse ori_kv use case, elements of `oriTopkLengthOptional` indicate the number of actually valid index entries, and the value must be within the range of [0, K]. For each q token and KV head, the [0, oriTopkLengthOptional) interval of `oriSparseIndicesOptional` contains left-aligned valid index entries, and the [oriTopkLengthOptional, K) interval contains invalid or padding entries, for which filling -1 is recommended. In other scenarios, pass in nullptr or an empty Tensor for `oriTopkLengthOptional`.
  - Reserved inputs such as `cmpTopkLengthOptional` can be passed in as nullptr or an empty Tensor. Other tensors that have been passed in do not support being empty.
  - The `metadataOptional` parameter must be passed in. It is generated by the `aclnnSparseFlashMlaMetadata` operator, and the shape is fixed to (1024,).
  - `cmpResidualKvOptional` is an optional input parameter of the main operator and `aclnnSparseFlashMlaMetadata`. After being passed in, it is used to restore the length before compression used by the cmp-side mask based on `cmp_len * cmpRatio + residual`. The main operator only allows this parameter to be passed in when cmpMaskMode is 3 and cmpRatio is not equal to 1. It is not allowed to be passed in when cmpMaskMode is 0 or cmpRatio is equal to 1.

- Input requirements for the three Attention use cases

  | Use case | oriKvOptional | cmpKvOptional | cmpSparseIndicesOptional | Description |
  | :--- | :----- | :----- | :----------------- | :--- |
  | SWA   | Must be passed in | Not passed in | Not passed in | Sliding window attention only |
  | CSA   | Must be passed in | Must be passed in | Must be passed in | Sliding window + TopK sparse compressed KV |
  | HCA | Must be passed in | Must be passed in | Not passed in | Sliding window + dense compressed KV |

- Layout constraints

  - `layoutQOptional` and `layoutKvOptional` only support the combinations "BSND"/"BSND", "TND"/"TND", "BSND"/"PA_BBND", and "TND"/"PA_BBND". In non-PA_BBND use cases, `layoutQOptional` and `layoutKvOptional` must be the same.
  - When `layoutQOptional` is TND, `cuSeqlensQOptional` must be passed in.
  - When `layoutKvOptional` is PA_BBND, `sequsedOriKvOptional` must be passed in, and `oriBlockTableOptional` must be passed in. In BSND use cases, `sequsedOriKvOptional` can be optionally passed in to override the valid oriKv length of each batch. In TND use cases, `cuSeqlensOriKvOptional` is used to express the oriKv sequence boundaries.
  - When `layoutKvOptional` is TND, `cuSeqlensOriKvOptional` must be passed in.
  - When `layoutKvOptional` is TND and `cmpKvOptional` exists, `cuSeqlensCmpKvOptional` must be passed in.
  - `sequsedCmpKvOptional` is an optional input for all layoutKvOptional values. When explicitly passed in, it is used to override the logical valid length on the cmp side.

uint16_t FloatToFp16(float f)
{
  uint32_t bits;
  std::memcpy(&bits, &f, sizeof(bits));
  uint32_t sign = (bits >> 31) & 0x1u;
  int32_t exp = static_cast<int32_t>((bits >> 23) & 0xffu) - 127 + 15;
  uint32_t mant = (bits >> 13) & 0x3ffu;
  if (exp <= 0) {
    return static_cast<uint16_t>(sign << 15);
  }
  if (exp >= 31) {
    return static_cast<uint16_t>((sign << 15) | 0x7c00u);
  }
  return static_cast<uint16_t>((sign << 15) | (static_cast<uint32_t>(exp) << 10) | mant);
}

float Fp16ToFloat(uint16_t h)
{
  uint32_t sign = (h >> 15) & 0x1u;
  uint32_t exp = (h >> 10) & 0x1fu;
  uint32_t mant = h & 0x3ffu;
  uint32_t f;
  if (exp == 0) {
    f = (sign << 31) | (mant << 13);
  } else if (exp == 31) {
    f = (sign << 31) | 0x7f800000u | (mant << 13);
  } else {
    f = (sign << 31) | ((exp + 127u - 15u) << 23) | (mant << 13);
  }
  float result;
  std::memcpy(&result, &f, sizeof(result));
  return result;
}
