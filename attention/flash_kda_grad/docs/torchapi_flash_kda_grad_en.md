## Function Description

- Function: Computes the training backward pass of Kimi Delta Attention (KDA), returning gradients of Q, K, V, the initial state, gate, beta and gate parameters. Supports variable-length sequences, grouped query attention (GQA) and backward computation for fused activations.
  - `flash_kda_grad_metadata`: Generates a backward schedule from input dimensions and effective sequence lengths.
  - `flash_kda_grad`: Consumes forward caches and upstream gradients and returns eight fixed gradient slots. Generate backward metadata before a direct call. With [FlashKDA autograd](../../flash_kda/docs/torchapi_flash_kda_en.md), the forward interface manages caches and invokes backward.
- Formulas: For one sequence and one value head, let $\bar q_t$ and $\bar k_t$ be the Q/K operands consumed by forward, normalized when L2 normalization is enabled. $\sigma$ denotes sigmoid; an omitted `dt_bias` means zero bias. The per-step log gate and state recurrence are:

$$
\ell_t=\begin{cases}
g_t, & \text{gate fusion disabled} \\
-\exp(A_{log})\operatorname{softplus}(g_t+dt_{bias}), & lower\_bound=\mathrm{None} \\
lower\_bound\cdot\sigma\!\left(\exp(A_{log})(g_t+dt_{bias})\right), & -5\le lower\_bound<0
\end{cases}
$$

$$
\widetilde H_t=H_{t-1}\operatorname{diag}(\exp(\ell_t)),\quad
\Delta v_t=b_t(v_t-\widetilde H_t\bar k_t),\quad
H_t=\widetilde H_t+\Delta v_t\bar k_t^T,\quad
o_t=scale\cdot H_t\bar q_t
$$

$$
L=\sum_t\langle do_t,o_t\rangle+\langle dht,H_{last}\rangle
$$

Without beta sigmoid fusion, $b_t=beta_t$. With fusion, $b_t=\sigma(beta_t)$, or $2\sigma(beta_t)$ when `allow_neg_eigval` is also enabled. State $H_t$ is stored as `(Dv,Dk)`.

Backward computes `(dq,dk,dv,dh0,dg,dbeta,dA,dBias)` for this loss; `dA` differentiates `A_log`. With normalization backward enabled, `dq/dk` differentiate Q/K before normalization. `dht=None` omits the final-state contribution to the loss.

The implementation uses chunks of 64 tokens and head dimensions of 128. By default, the backward kernel reconstructs seven caches; `disable_recompute=True` consumes saved caches. Saved `chunk_states` are bfloat16; the recompute state buffer and state gradients are float32. The host selects persistent or staged scheduling and launches one main backward compute kernel.

## Prototype

Import the module with `import cann_ops_transformer`. Call `flash_kda_grad_metadata` first. Arguments from `batch_size` onward are keyword-only; the four required dimensions have no defaults.

```python
cann_ops_transformer.flash_kda_grad_metadata(
    cu_seqlens=None,
    seqused=None,
    batch_size=batch_size,
    nheads_qk=nheads_qk,
    nheads_v=nheads_v,
    seqlens=seqlens,
    headdim_qk=128,
    headdim_v=128,
    layout='TND',
)
```

For `flash_kda_grad`, arguments from `Aqk` onward are keyword-only. `Aqk` and `Akk` are required Tensors with no defaults. `dht` is optional and defaults to `None`, meaning a zero final-state gradient. `metadata` defaults to `None`, but execution requires a snapshot generated by `flash_kda_grad_metadata`.

```python
cann_ops_transformer.flash_kda_grad(
    q,
    k,
    v,
    g,
    beta,
    do,
    dht=None,
    Aqk=Aqk,
    Akk=Akk,
    metadata=None,
    initial_state=None,
    chunk_states=None,
    w=None,
    u=None,
    v_new=None,
    qg=None,
    kg=None,
    g_cumsum=None,
    q_rstd=None,
    k_rstd=None,
    beta_sigmoid=None,
    A_log=None,
    dt_bias=None,
    cu_seqlens=None,
    cu_seqlens_cpu=None,
    seqused=None,
    scale=None,
    use_qk_l2norm_in_kernel=True,
    use_gate_in_kernel=True,
    use_beta_sigmoid_in_kernel=True,
    allow_neg_eigval=False,
    disable_recompute=False,
    lower_bound=None,
    layout='TND',
    dbeta_dtype=None,
)
```

## Parameters

`B` is the logical sequence count, `S` the physical BNSD/BSND sequence length and `T` the total TND token count. `Nqk` and `Nv` are the Q/K and value head counts, with `Nv % Nqk == 0`; each Q/K head serves `Nv/Nqk` consecutive value heads. Currently `Dk=Dv=128`, chunk size is fixed at 64, and tensors use ND format.

### Input Layouts

`layout` specifies Q/K/V layout. For dense layouts, g, beta and do always place the sequence dimension before the head dimension.

| layout | q, k | v | g | beta | do |
| --- | --- | --- | --- | --- | --- |
| BNSD | `(B,Nqk,S,128)` | `(B,Nv,S,128)` | `(B,S,Nv,128)` | `(B,S,Nv)` | `(B,S,Nv,128)` |
| BSND | `(B,S,Nqk,128)` | `(B,S,Nv,128)` | `(B,S,Nv,128)` | `(B,S,Nv)` | `(B,S,Nv,128)` |
| TND | `(T,Nqk,128)` | `(T,Nv,128)` | `(T,Nv,128)` | `(T,Nv)` | `(T,Nv,128)` |

### Forward Cache Layouts

Both dense layouts share the cache layouts below. Pass normalized `q_norm/k_norm` through the main interface's q/k arguments, preserving the corresponding Q/K input shapes. Their inverse norms use head-major storage.

| Cache | TND | BNSD / BSND | Data type |
| --- | --- | --- | --- |
| q_rstd, k_rstd | `(Nqk,T)` | `(B,Nqk,S)` | float32 |
| beta_sigmoid | `(Nv,T)` | `(B,Nv,S)` | float32 |
| Aqk, Akk | `(Nv,T,64)` | `(B,Nv,S,64)` | bfloat16 |
| w, qg, kg | `(Nv,T,128)` | `(B,Nv,S,128)` | bfloat16 |
| u, v_new | `(Nv,T,128)` | `(B,Nv,S,128)` | bfloat16 |
| g_cumsum | `(Nv,T,128)` | `(B,Nv,S,128)` | float32 |
| chunk_states | `(Nc,Nv,128,128)` | `(B,Cmax,Nv,128,128)` | bfloat16 |

`Cmax=ceil(S/64)` and `Nc=ceil(T/64)+B`. TND state storage includes reserved slots: chunk j of sequence b occupies `floor(cu_seqlens[b]/64)+b+j`; consume only that sequence's `ceil(length_b/64)` valid slots. Aqk/Akk use token-row addressing, with 64 block-local columns; tail blocks are zero-padded in workspace.

### Cache and Recompute Modes

| Parameter | `disable_recompute=False` (default) | `disable_recompute=True` |
| --- | --- | --- |
| chunk_states, w, u, v_new, qg, kg, g_cumsum | May be omitted and are reconstructed internally. Explicitly supplied tensors still undergo public shape checks. | All seven are required and must come from the same forward call. |
| initial_state | Required to reconstruct a nonzero initial state; `None` means zero initial state. | Cache evaluation does not read it, but supply the corresponding initial state when dh0 is needed. |
| Aqk, Akk | Required; not reconstructed. | Required. |
| q_rstd, k_rstd | Required with Q/K normalization backward. | Required with Q/K normalization backward. |
| beta_sigmoid | Required with beta sigmoid fusion. | Required with beta sigmoid fusion. |

| Name | Type | Required/Optional | Description | Data type | Format | Shape |
| --- | --- | --- | --- | --- | --- | --- |

### flash_kda_grad

Always returns `(dq,dk,dv,dh0,dg,dbeta,dA,dBias)`. Optional outputs retain their slots when `None`; the tuple always contains eight entries.

| Name | Type | Required/Optional | Description | Data type | Format | Shape |
| --- | --- | --- | --- | --- | --- | --- |
| dq | Tensor | Required | Q gradient, including L2-normalization backward when enabled and the reduction over corresponding value heads for GQA. | bfloat16 | ND | Same as `q`. |
| dk | Tensor | Required | K gradient, with the same normalization and GQA semantics as dq. | bfloat16 | ND | Same as `k`. |
| dv | Tensor | Required | V gradient, with the shape and logical layout of v. | bfloat16 | ND | Same as `v`. |
| dh0 | Tensor | Optional | Initial-state gradient. Returns `None` when `initial_state=None`, and a float32 Tensor otherwise. | float32 | ND | `(B,Nv,128,128)` |
| dg | Tensor | Required | Gate-input gradient, preserving the dtype and shape of g. Without fusion, it is the gradient of the per-step log gate. | g.dtype | ND | Same as `g`. |
| dbeta | Tensor | Required | Beta-input gradient, with the shape of beta and the dtype selected by dbeta_dtype. Without fusion, it differentiates the activated coefficient. | beta.dtype / bfloat16 | ND | Same as `beta`. |
| dA | Tensor | Optional | Gradient of A_log. Returns `None` when gate fusion is disabled. | float32 | ND | `(Nv,)` |
| dBias | Tensor | Optional | Gradient of dt_bias, with the same shape. Returns `None` when gate fusion is disabled or `dt_bias=None`. | float32 | ND | Same as `dt_bias`. |

## Constraints

### Common Constraints

- This interface provides single-operator execution for training backward. Actual computation runs on NPU. Meta/FakeTensor supports output-specification inference and does not validate device execution.
- `B>=1`, `S>=0`, `T>=0`, `1<=Nqk<=Nv` and `Nv % Nqk == 0`; head dimensions are fixed at 128. Integer metadata dimensions and its `8+7*B*Nv` capacity must fit int32. Joint use with FlashKDA must also satisfy the forward interface's specifications.
- All consumed inputs, caches and metadata must be on the same NPU; select the current device before calling. Length and metadata tensors must be contiguous. Q/K/V and consumed caches must have contiguous last dimensions. Preserve forward cache views rather than transposing every cache to the input layout. The host materializes do/dht views when their transfer layout requires it.
- `do` must be a bfloat16 Tensor; `dht` may be `None`. The public Torch interface returns a float32 dh0 Tensor when `initial_state` is supplied, and `None` otherwise.
- Outputs are not guaranteed contiguous; for example, dA may be a column view of internal storage. Call `.contiguous()` when required downstream. Padded BNSD/BSND gradient rows are zero. For an empty sequence, returned dh0 propagates dht, or zero when dht is omitted.

### Cache and Fusion Constraints

- All caches must come from the same forward call, with matching layout, scale, initial state and fusion attributes. The main interface does not normalize raw Q/K again. When normalization backward is enabled, supply saved q_norm/k_norm and float32 inverse norms.
- With gate fusion, g must be bfloat16 and float32 A_log is required; without fusion, g must be a float32 per-step log gate. With beta sigmoid fusion, beta must be bfloat16 and float32 beta_sigmoid is required; without fusion, beta must be the float32 activated coefficient.
- `allow_neg_eigval=True` requires beta sigmoid fusion; beta_sigmoid already includes the factor of 2. Disabling gate fusion suppresses dA/dBias; omitting dt_bias suppresses dBias.
- Only the seven caches listed in [cache and recompute modes](#cache-and-recompute-modes) may be omitted for recompute. Retain Aqk/Akk and all required inverse-norm and activation caches. Different intermediate rounding may affect recompute and saved-cache modes; the modes need not be bitwise identical.
- `dbeta_dtype` does not change beta's input requirements. A float32 beta input may request bfloat16 dbeta; a bfloat16 beta input cannot use this option to request float32 output.

### Sequence Length and Metadata Constraints

- Generate backward metadata using `flash_kda_grad_metadata`. TND accepts only cu_seqlens; BNSD/BSND accept only seqused. The two are mutually exclusive. TND schedule generation requires cu_seqlens and allows equal adjacent boundaries. Omitted dense seqused means length S for every sequence.
- The main backward call may use metadata without repeating length tensors. Explicit lengths must match the boundaries and effective lengths recorded in metadata. Regenerate metadata after changing dimensions, device, layout or effective lengths; do not edit task records manually.
- Forward and backward metadata have different protocols. Direct backward uses its own backward metadata. Autograd uses the combined schedule from `flash_kda_metadata(enable_grad=True)`, and the forward interface extracts the backward portion.
- Second-order gradients are not provided. Use FlashKDA's training entry for autograd integration with this backward operator.

## Determinism and Batch Consistency

- Determinism: Supported by default. For the same device, inputs, attributes, metadata and core partitioning, gate-parameter gradients accumulate in separate per-vector-core buffers and are then reduced in a fixed order. End-to-end FlashKDA autograd also depends on the forward interface's determinism constraints.
- Batch consistency: Not supported by default. Changing batches or sequence grouping may change work partitioning and reduction paths; bitwise equality across batch combinations or different schedules is not guaranteed.

## Examples

The examples require matching CANN, CANNBotDSL, PyTorch and torch_npu installations, an installed cann_ops_transformer package, and both FlashKDA and FlashKDAGrad extensions. Both examples use single-operator execution. The forward protocol depends on `torch.is_inference_mode_enabled()`; generate training caches in normal mode or under `torch.no_grad()`.

### Autograd Through FlashKDA

The forward interface saves caches and invokes backward. This example uses recompute; set the forward `disable_recompute` option to `True` for saved-cache mode.

```python
import torch
import torch_npu
import cann_ops_transformer as ops

torch.npu.set_device(0)
batch, length, n_qk, n_v, dim = 1, 65, 1, 2, 128

# Training uses BSND inputs; fused g and beta are bfloat16.
q = torch.randn(batch, length, n_qk, dim, device="npu",
                dtype=torch.bfloat16, requires_grad=True)
k = torch.randn_like(q, requires_grad=True)
v = torch.randn(batch, length, n_v, dim, device="npu",
                dtype=torch.bfloat16, requires_grad=True)
g = torch.randn_like(v, requires_grad=True)
beta = torch.randn(batch, length, n_v, device="npu",
                   dtype=torch.bfloat16, requires_grad=True)
initial_state = torch.zeros(batch, n_v, dim, dim, device="npu",
                            dtype=torch.float32, requires_grad=True)
A_log = torch.full((n_v,), -3.5, device="npu",
                   dtype=torch.float32, requires_grad=True)
dt_bias = torch.zeros(n_v, dim, device="npu",
                      dtype=torch.float32, requires_grad=True)

# Generate the combined forward/backward schedule for autograd.
metadata = ops.flash_kda_metadata(
    batch_size=batch, nheads_qk=n_qk, nheads_v=n_v,
    seqlens=length, enable_grad=True, layout="BSND",
)
out, final_state, chunk_states = ops.flash_kda(
    q, k, v, g, beta, metadata, initial_state=initial_state,
    A_log=A_log, dt_bias=dt_bias, output_final_state=True,
    disable_recompute=False, layout="BSND",
)

# FlashKDA invokes FlashKDAGrad and manages its caches internally.
loss = out.float().square().mean() + final_state.square().mean()
loss.backward()
torch.npu.synchronize()
assert q.grad.shape == q.shape and v.grad.shape == v.shape
assert initial_state.grad.shape == initial_state.shape
assert A_log.grad.shape == A_log.shape
assert chunk_states is None
```

### Direct Saved-Cache and Recompute Backward

This example obtains 16 training outputs through the registered `flash_kda_fwd` interface. Public `flash_kda` returns only the first three entries; use the autograd example above for ordinary training.

```python
import torch
import torch_npu
import cann_ops_transformer as ops

torch.npu.set_device(0)
batch, length, n_qk, n_v, dim = 1, 65, 1, 2, 128
scale = dim ** -0.5
q = torch.randn(batch, n_qk, length, dim, device="npu", dtype=torch.bfloat16)
k = torch.randn_like(q)
v = torch.randn(batch, n_v, length, dim, device="npu", dtype=torch.bfloat16)

# Even with BNSD Q/K/V, g and beta use BSND/BSN storage.
g = torch.randn(batch, length, n_v, dim, device="npu", dtype=torch.bfloat16)
beta = torch.randn(batch, length, n_v, device="npu", dtype=torch.bfloat16)
initial_state = torch.zeros(batch, n_v, dim, dim, device="npu", dtype=torch.float32)
A_log = torch.full((n_v,), -3.5, device="npu", dtype=torch.float32)
dt_bias = torch.zeros(n_v, dim, device="npu", dtype=torch.float32)

# Use the registered 16-slot forward entry to obtain real training caches.
# no_grad() keeps the training cache protocol; do not use inference_mode().
with torch.no_grad():
    forward_metadata = ops.flash_kda_metadata(
        batch_size=batch, nheads_qk=n_qk, nheads_v=n_v,
        seqlens=length, enable_grad=False, layout="BNSD",
    )
    forward_outputs = torch.ops.cann_ops_transformer.flash_kda_fwd(
        q, k, v, g, beta, forward_metadata,
        initial_state=initial_state, A_log=A_log, dt_bias=dt_bias,
        scale=scale, output_final_state=True,
        disable_recompute=True, layout="BNSD",
    )

(out, final_state, chunk_states, Aqk, Akk, w, u, qg, kg, v_new,
 g_cumsum, q_norm, q_rstd, k_norm, k_rstd, beta_activated) = forward_outputs
do = torch.randn_like(out)

# Direct backward takes its own metadata, not the forward schedule.
backward_metadata = ops.flash_kda_grad_metadata(
    batch_size=batch, nheads_qk=n_qk, nheads_v=n_v,
    seqlens=length, layout="BNSD",
)
common = dict(
    Aqk=Aqk, Akk=Akk, metadata=backward_metadata,
    initial_state=initial_state, q_rstd=q_rstd, k_rstd=k_rstd,
    beta_sigmoid=beta_activated, A_log=A_log, dt_bias=dt_bias,
    scale=scale, layout="BNSD",
)

# Saved-cache mode consumes all seven caches; omitted dht means zero.
saved = ops.flash_kda_grad(
    q_norm, k_norm, v, g, beta, do, **common,
    chunk_states=chunk_states, w=w, u=u, v_new=v_new,
    qg=qg, kg=kg, g_cumsum=g_cumsum, disable_recompute=True,
)

# Recompute mode retains Aqk/Akk and the normalization/activation caches.
rebuilt = ops.flash_kda_grad(
    q_norm, k_norm, v, g, beta, do, **common,
    disable_recompute=False,
)
torch.npu.synchronize()
for gradients in (saved, rebuilt):
    dq, dk, dv, dh0, dg, dbeta, dA, dBias = gradients
    assert dq.shape == q.shape and dv.shape == v.shape
    assert dg.shape == g.shape and dbeta.shape == beta.shape
    assert dh0.shape == initial_state.shape
    assert dA.shape == A_log.shape and dBias.shape == dt_bias.shape
```

The forward return protocol is described in the [FlashKDA interface documentation](../../flash_kda/docs/torchapi_flash_kda_en.md).
