## Description

- Operator function: KeyPool is a Key compression operator in the inference scenario. The operator performs K
projection and Gate projection on each input token, groups every `cmpRatio` consecutive tokens into one group, merges
the K values within a group into one Key according to the weights determined by the Gate and the position bias, and writes
the intermediate state required by incomplete compression groups into the paged
`stateCache`.

- Calculation formula:

  For each token in the current input:

  ```text
  K = hiddenStates @ wk.T
  G = hiddenStates @ gateWeight.T
  K_norm = LayerNorm(K, dim=-1)  # when normWeightOptional/normBiasOptional are provided
  ```

  For the `q`-th global compression group:

  ```text
  logits[q, r] = G[q * cmpRatio + r] + ape[r]
  weight = softmax(logits, dim=0)
  pooled[b, q - startPool[b]] = sum(weight[r] * K_norm[q * cmpRatio + r], dim=0)
  ```

  Historical tokens are read from `stateCache` through `cacheBlockTable`. For the projection result of
  the current input tokens, the data generated by the current call is used preferentially. For scenarios where
  `startPos` is not aligned with `cmpRatio`, the first compression group can be composed of historical tokens and
  current input tokens. `ape` participates only in the pooling computation
  and is not written to `stateCache`. The RoPE parameter entry is reserved for future extensions, but the current version does not implement RoPE.

  LayerNorm is computed independently along the last dimension `D` of each token and does not reduce across tokens.

where:

- `D` is the head dimension of K and Gate, determined by dimension 0 of `wk`;
- `R=cmpRatio`;
- `N` is the number of physical blocks;
- `BS` is the block size;
- `L` is the maximum number of logical blocks per Batch;
- The BSH output is `[B,Sr,D]`, where `Sr=ceil(S/cmpRatio)`.
- The TH output is `[Tr,D]`, where `Tr=min(T,floor(T/cmpRatio)+B)`.
- The number of valid rows of each Batch is `n[b]=floor((startPos[b]+seqLen[b])/cmpRatio)-floor(startPos[b]/cmpRatio)`.
  BSH places the valid results in `pooledKeyOut[b,:n[b]]`; TH concatenates the valid results continuously in Batch order,
  and the start point of the b-th Batch is the sum of `n` of all preceding Batches. Other output rows are not initialized.
- `BSH`: the Batch-Sequence-Hidden input layout. The shape of `hiddenStates` is
  `[B,S,H]`. `B` indicates BatchSize, `S` indicates the sequence length of the current input of each
  Batch, and `H` indicates hiddensize.
- `TH`: the Token-Hidden input layout. The shape of `hiddenStates` is `[T,H]`.
  `T` indicates the total number of input tokens of all Batches; `cuSeqlensOptional`
  is a prefix sum array with the shape `[B+1]`, used to describe the token boundaries of each Batch on the first axis.
- `RoPE`: Rotary Position Embedding, a position encoding method that usually uses `cos`
  and `sin` to rotate paired channels in the last dimension of K. This operator currently keeps only the RoPE
  parameter entry and does not execute RoPE. `cosOptional` and `sinOptional` must be null pointers.

Input tensors use the ND format. `stateCacheRef` is an in-place input, used to save the state of incomplete
compression groups across operator calls.

## Constraints

- `D` supports only `128/512`; `H` must be within the range `[1024,10240]` and be an integer multiple of `512`.
- Both the BSH and TH scenarios are supported:
  - In the BSH scenario, `cuSeqlensOptional` must be empty;
  - In the TH scenario, a valid `cuSeqlensOptional` prefix sum array must be provided. The first element is 0,
    the last element is `T`, and the array is monotonically non-decreasing.
- `cmpRatio` supports only `2/4/8/16/32/64/128`; `normEps` must be greater than 0;
  `rotaryMode` supports only `0/1`.
- `normWeightOptional` and `normBiasOptional` must be provided together or be empty together.
- `cosOptional` and `sinOptional` must be empty because RoPE is not currently supported;
  `sequsedOptional` must be empty because selecting tokens through `attention_mask` is not currently supported.
- `B=0` or `S=0` in the BSH scenario and `T=0` in the TH scenario are supported.
- The default value of `cmpRatio` is 4, and the value range is `2/4/8/16/32/64/128`.
- The default value of `normEps` is `1e-6`, and the value range is greater than 0.
- The default value of `rotaryMode` is 1, and the value range is `0/1`. RoPE is not currently executed.
